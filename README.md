##### くわしい紹介



**・train-stop.html**

珀南鉄道の珀南本線（架空）を運転します。1.6アップデートで特急とかも運転できるよ

1.7アップデートでは乗り鉄の時、フリーカムとか運行状況が確認できるようになったよ

1.8アップデートで神麓胡駅まで延伸して寝台列車に乗れるようになったよ

1.9アップデートでH1000系の車内更新、側面の行先表示機アプデとN10系のVVVF更新をしたよ

1.10アップデートでH1200系とか快急とか音系のアプデとかしてますよ

～珀南鉄道の車両一覧(最終更新11月16日、1.10.2)～

H1000系 - Claudeが一から作ったもの モーター音と展望席以外は全部Claudeまかせ

H1200系 - 俺が全部Claudeに指示して作ったもの（遊ぶならおすすめ）

N10系 - 俺が工作で作った車両を3D化させたもの 特急専用車

s13n系 -  夜行特急専用車、N10系ベース





**・device-tycoon**

タイクーンゲーが好きなので作らせてみたら、まあまあな完成度のものができた

スマホとかパソコン、タブレットを作って経営を体験するゲームだよ

1.0.0アップデートでちょとだけ面白くなったぞ！！！！！！！！！



**・Ctrl/Sim**

MMORPG初代のイメージで新しいタイクーンゲー作ってみたけど、

人によっては普通につまらなさすぎてすぐ飽きるかもしれん

**・かんたんmodインストーラー**

これ一個でいろんなmodを入れて、しかもそれをプロファイルごとに管理できるよってだけ

多分調べたら俺のやつよりもマシなやつがあると思う

・glb-viewer

これは普通に俺がglbファイルをみることがあるから個人的に作らせた

・kr-time

Nimby Railsでなぜか時刻表をjson形式でエクスポートできたから、時刻表と乗換案内作れるかなと思ったら

Claude有能すぎて普通に作ってくれた

・links

これは普通にまとめリンク集
