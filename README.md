ここはClaudeかDevin/Cursorでバイブコーディングしたものを置くだけです



紹介

・glb-viewer

これは普通に俺がglbファイルをみることがあるから個人的に作らせた

・kr-time

Nimby Railsでなぜか時刻表をjson形式でエクスポートできたから、時刻表と乗換案内作れるかなと思ったら

Claude有能すぎて普通に作ってくれた

・links

これは普通にまとめリンク集

・train-stop.html

あさひ → みどり台 → さくら坂 の3駅を走ります。

難易度をちょっと下げたのでたぶん初見でも運転しやすいかもしれない。

・かんたんmodインストーラー

これ一個でいろんなmodを入れて、しかもそれをプロファイルごとに管理できるよってだけ

多分調べたら俺のやつよりもマシなやつがあると思う

・device-tycoon

タイクーンゲーが好きなので作らせてみたら、まあまあな完成度のものができた



（広告）

マイクラのjava版のmod管理がめんどくさい！

そんなときはEasyModInstaller.exe(windows)を試してみよう！

自分の好きなmodの組み合わせが登録できるぞ！
